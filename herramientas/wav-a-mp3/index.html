🎧 Conversor de WAV a MP3

Convierte tus archivos .wav a .mp3 directamente en tu navegador. Ningún archivo se sube a Internet: todo el procesamiento ocurre en tu equipo.
⬆️

Arrastra aquí tus archivos WAV
o haz clic para elegirlos

    ⚠️ Tu navegador no permite ejecutar Web Workers desde archivos locales. Usa la versión publicada en el sitio o un navegador moderno.

    ¿Cómo funciona?

    • El audio WAV se decodifica con la API de audio del navegador.
    • Se codifica a MP3 con lamejs (el codificador LAME compilado a JavaScript).
    • El trabajo pesado corre en un Web Worker para que la página no se congele.
    • Formatos de entrada: WAV PCM (8/16/24/32 bits). Frecuencias admitidas por MP3: 8–48 kHz.
