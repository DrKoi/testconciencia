# ModelTasker TDAH

Aplicación de gestión de tareas de mínima fricción para TDAH Inatento:
Foco Único (WIP=1), Micro-Acción Just-In-Time, Parking Lot y Cierre
Dopaminérgico. 100% local — corre entero en el navegador, sin backend,
datos solo en `localStorage`.

- **`index.html`** — la app en sí. Ábrelo directo en el navegador, sin servidor.
- **`app/`** — proyecto fuente (TypeScript + Vite) del que se compila `index.html`. Ver `app/README.md` para desarrollo.
- **`legacy_v1/`** — primera versión (archivo único) y sus tests de esa época, conservada como referencia histórica.
- **`INVESTIGACION_TDAH_INATENTO.md`** / **`AUDITORIA_EVIDENCIA_FUENTES.md`** — la investigación académica y su auditoría adversaria de fuentes (niveles de certeza 1-4) en las que se fundamenta el diseño.
- **`MANUAL_OPERATIVO_TDAH.md`** — guía de uso diario.
- **`POOL_APLICACIONES_FUTURAS.md`** / **`PROGRESS.md`** — backlog de ideas derivadas de la misma investigación (incluye TabWIP, en `herramientas/tabwip/`) y estado del proyecto para retomar.
