🧹 Limpiar metadatos

Quita los datos ocultos de tus archivos antes de compartirlos: ubicación GPS, modelo de cámara, fechas, autor, empresa, software y comentarios. Imágenes, PDF, documentos de Office/LibreOffice y audio. Todo ocurre en tu navegador; ningún archivo se sube a Internet.

JPEG · PNG · WebP · GIF · SVG · PDF · MP3 · FLAC · M4A · DOCX · XLSX · PPTX · ODT · RTF

    ⚠️ Este navegador no puede cargar la librería de PDF desde un archivo local. Usa la versión publicada en el sitio para limpiar PDF.

    ¿Qué hace exactamente?

    • Imágenes (JPEG, PNG, WebP): elimina los bloques de metadatos sin volver a comprimir los píxeles — EXIF, XMP, IPTC y comentarios. El perfil de color (ICC) se conserva. Modo máximo recomprime la imagen para garantizar que no queda nada.
    • GIF y SVG: quita comentarios y bloques de texto/XMP del GIF; en SVG borra <metadata>, comentarios y los datos del editor (Inkscape/Sodipodi).
    • PDF: vacía el diccionario /Info (título, autor, asunto, palabras clave, programa, fechas) y elimina el XMP. Con pdf-lib.
    • Documentos (DOCX, XLSX, PPTX, ODT, ODS, ODP): reemplaza las propiedades del documento (autor, «última modificación por», empresa, responsable, plantilla, revisión, tiempo de edición, propiedades personalizadas) por versiones vacías y elimina la miniatura. El contenido no se toca.
    • Audio (MP3, FLAC, M4A): borra etiquetas ID3, APEv2, comentarios Vorbis, carátulas y las etiquetas de iTunes (incluida la ubicación GPS y la cuenta de Apple ID). No recodifica el audio.
    • RTF: elimina el grupo \info, el generador y la tabla de revisiones.
    • El original nunca se modifica: descargas una copia nueva con el sufijo -limpio. Funciona sin conexión una vez cargada la página.

    Nota: quitar metadatos no anonimiza el contenido. Una foto puede seguir mostrando tu calle y un documento puede llevar tu nombre en el texto. Esto solo limpia los datos incrustados que no se ven. Para vídeo (MP4/MOV) todavía no; escríbeme si lo necesitas.
